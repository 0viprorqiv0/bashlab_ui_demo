Create directories and files (mkdir, touch)

In everyday shell workflows, creating directory trees and initializing placeholder or config files is essential. You'll use mkdir to create folders and touch to create empty files safely.

{} Command Syntax POSIX
mkdir [OPTIONS] DIRECTORY...
touch [OPTIONS] FILE...
-p Create parent directories as needed touch Create empty file or update timestamp
